# Für Elise (Beethoven, WoO 59)

`fur_elise.mid` comes from the [Mutopia Project](https://www.mutopiaproject.org/) and is in the public domain. Track 1 is the right hand; we play its first 25.3 seconds (86 notes, C4 to E6).

Beethoven's piece is not part of the FürElise dataset, so there is no human motion for it.
